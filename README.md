# Vue Dashboards

Six responsive Vue 3 dashboard views covering web analytics, finance, marketing, store operations, commerce growth, and observability.

## Run

```sh
npm install
npm run dev
```

Use the dashboard selector in the top bar, or open `/#dashboard-5` through `/#dashboard-10`.

```sh
npm run build
npm run preview
```

The implementation uses Vue 3, Vite, Lucide icons, locally bundled Geist fonts, and custom SVG charts. It includes chart hover values, report-period controls, searchable and sortable transactions, CSV exports, sidebar controls, appearance settings, search, and local demo forms. Data is illustrative; no backend or external accounts are connected.
